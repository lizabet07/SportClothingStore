# SportClothingStore

## Система управления базой данных магазина спортивной одежды

Учебный проект по дисциплине «Базы данных», разработанный в MS SQL Server с использованием языка T-SQL.

### О проекте

База данных предназначена для автоматизации работы склада-магазина спортивной одежды.

**Основные возможности:**
- Учёт товаров, категорий, размеров, цветов и фасонов.
- Контроль складских остатков.
- Регистрация покупателей и продаж.
- Учёт поставщиков и заказов.
- Автоматическое формирование заявки поставщику при остатке менее 6 единиц.
- Поиск товаров по названию.
- Регистрация поступлений на склад.

### Технологии

- Microsoft SQL Server
- T-SQL
- SQL Server Management Studio (SSMS)

### Структура базы данных

База данных содержит 13 таблиц, 3 представления (VIEW), 3 функции (FUNCTION), 4 хранимые процедуры (PROCEDURE) и 1 триггер (TRIGGER).
