# SportClothingStore

## Склад-магазин спортивной одежды — вариант №32

Учебный проект по дисциплине «Базы данных». Реализован на **Microsoft SQL Server (T-SQL)**, запуск и проверка — через **SQL Server Management Studio (SSMS)**.

### Возможности
- Каталог спортивной одежды по категориям, фасонам, размерам и цветам.
- Учёт покупателей, продаж, складских остатков и поставщиков.
- Поиск товаров по названию.
- Хранимые процедуры для оформления продажи, пополнения склада и приёма поставки.
- Автоматический заказ поставщику при **переходе остатка с 6 и более до значения меньше 6**. Заявка пополняет остаток до 15 единиц; повторная заявка не создаётся, пока есть открытая.
- Проверка полного цикла: остаток 8 → продажа 4 → остаток 4 → заявка на 11 → приём поставки → остаток 15.

### Состав базы
- **13 таблиц**: `Categories`, `Colors`, `Sizes`, `Styles`, `Products`, `ProductVariants`, `Stock`, `Suppliers`, `Customers`, `Sales`, `SaleItems`, `SupplyOrders`, `SupplyOrderItems`.
- **3 представления**: `vw_ProductCatalog`, `vw_StockBalance`, `vw_LowStock`.
- **3 функции**: `fn_GetStock`, `fn_GetProductStock`, `fn_GetSaleTotal`.
- **4 процедуры**: `sp_CreateSale`, `sp_SearchProducts`, `sp_AddStock`, `sp_ReceiveSupply`.
- **1 триггер**: `trg_LowStock`.

### Как запустить с нуля
1. Откройте SSMS и подключитесь к SQL Server.
2. Убедитесь, что в экземпляре **нет базы `SportClothingStore`**. Если база уже существует, **не запускайте `01_CreateTables.sql` повторно**: используйте отдельный экземпляр сервера или предварительно адаптируйте имя базы во всех скриптах для тестирования.
3. Выполните скрипты **01–06 последовательно** — каждый после успешного выполнения предыдущего.
4. Выполните **10**, затем **09** для проверки структуры.
5. Запустите **07** и **08** для тестирования поведения. В обоих тестах изменения отменяются через `ROLLBACK`.

> Скрипты 01–02 рассчитаны на первоначальное создание и заполнение новой базы, а не на повторный запуск поверх существующих таблиц и данных. Тест 08 предполагает исходный остаток варианта №2 в количестве 8 единиц.

### Проверка
Для варианта `VariantID = 2` ожидается:
- До продажи — **8 шт.**
- После продажи 4 шт. — **4 шт.**
- Автоматическая заявка — **11 шт.**
- После приёма поставки — **15 шт.**, статус `Получен`.
- `ROLLBACK` отменяет тестовые изменения.
